# 🎵 Yandex Music Downloader

Десктопное приложение на Electron для скачивания треков с Яндекс Музыки.
Красивый тёмный UI, поддержка ID3 тегов, скачивание обложек.

---

## ✨ Возможности

- 🔍 **Поиск** треков, альбомов, плейлистов, артистов
- 🔗 **Скачивание по ссылке** (трек / альбом / плейлист)
- ❤️ **Лайкнутые треки** — скачать всё, что вам нравится
- 📁 **Пакетное скачивание** — выбирайте несколько треков
- 🎨 **ID3 теги** — автоматически встраиваются название, артист, альбом, обложка
- ⚡ **Параллельные загрузки** — до 5 треков одновременно
- 💾 **Настраиваемый шаблон имени файла**

## 🚀 Установка

### Требования
- Node.js 18+
- npm 9+

### Шаги

```bash
# 1. Перейдите в папку проекта
cd yandex-music-downloader

# 2. Установите зависимости
npm install

# 3. Запустите приложение
npm start
```

## 🔑 Получение OAuth токена

Токен нужен для доступа к API Яндекс Музыки.

### Способ 1 (через браузер)

1. Откройте: https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
2. Авторизуйтесь в Яндексе
3. Скопируйте `access_token` из URL после редиректа

### Способ 2 (через YandexMusicToken)

Используйте утилиту [yandex-music-token](https://github.com/MarshalX/yandex-music-api#api-token) для получения токена.

### Способ 3 (через приложение Android)

1. Включите прокси (например, Charles Proxy)
2. Откройте Яндекс Музыку и войдите
3. В запросах найдите заголовок `Authorization: OAuth <token>`

Токен выглядит примерно так: `y0_AgAAAA...` или `AQAAAAAyour_token...`

## ⚙️ Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| Папка сохранения | `~/Downloads` | Куда сохранять файлы |
| Шаблон имени | `{artist} - {title}` | Теги: `{artist}`, `{title}`, `{album}`, `{year}`, `{id}` |
| Параллельные загрузки | `2` | 1–5 одновременных загрузок |
| Скачивать обложки | `вкл` | Встраивать обложку в ID3 |
| Пропускать существующие | `вкл` | Не перезаписывать файлы |

## 🔒 Безопасность

- Токен хранится локально в `userData/settings.json`
- Нет передачи данных на сторонние серверы
- Все запросы идут напрямую к API Яндекс Музыки

---

## ⚠️ Дисклеймер

Приложение предназначено **только для личного использования** треков, на которые у вас есть право (подписка Яндекс Музыки). Не распространяйте скачанные треки — это нарушает авторские права.

## 🛠 Стек

- **Electron 28** — десктопная оболочка
- **Node.js** — основная логика, HTTP-загрузка
- **axios** — HTTP-клиент для API
- **node-id3** — запись ID3 тегов в MP3
- **sanitize-filename** — безопасные имена файлов
- **Vanilla JS + CSS** — UI без фреймворков
